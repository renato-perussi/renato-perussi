Minha base é em **Ciências Econômicas**, com formação técnica em **Tecnologia**. Hoje aprofundo meus estudos em **Análise,  Ciência de Dados** e **Desenvolvimento Web**, usando Python como ferramenta principal.

## Projetos em destaque

**📊 [seller_analytics_mercado_livre](https://github.com/renato-perussi/seller_analytics_mercado_livre)**  
Painel full-stack (React + Python) para performance comercial no Mercado Livre: ingestão de CSVs, KPIs executivos, evolução temporal e conciliação financeira (bruto → líquido).

**📈 [B3_Stocks_Dashboard](https://github.com/renato-perussi/B3_Stocks_Dashboard)**  
Dashboard em Streamlit para análise estatística de ações da B3, com visualizações financeiras e foco em suporte à decisão.

**🏠 [CFI](https://github.com/renato-perussi/CFI)**  
Ferramenta gratuita para simular e comparar financiamentos imobiliários pelos sistemas SAC e Price (React + TypeScript).

**🛒 [Vendas_Mercado_Livre](https://github.com/renato-perussi/Vendas_Mercado_Livre)**  
Dashboard em Streamlit para análise de vendas: receita, desempenho por produto, sazonalidade e distribuição geográfica.
